# AH-13 DA-15: config preservation

Design recorded before implementation: retain unknown raw JSON fields on CLIConfig, BackendOverrides and OpenClawOverride using custom JSON marshal/unmarshal methods. Known fields remain authoritative, including omitempty deletion and nil backend deletion. Unknown values retain JSON types and number precision. Derive known field names from struct tags, including case-insensitive matching consistent with encoding/json, so adding a typed field cannot resurrect an old unknown value. Keep the existing atomic save path and permissions.

Scope: existing configuration serialization defect, not a bridge regression. Tests use synthetic config in a private source copy outside the task marker tree. No existing config, account credentials, bridge or service changes.
